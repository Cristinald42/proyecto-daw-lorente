# Diagramas de `docs/`

Los diagramas **canónicos** de la documentación están escritos en **Mermaid** dentro de `01-analisis.md` y `01b-sota.md`. GitHub los renderiza sin necesidad de imágenes.

En esta carpeta se guardan:

- Las fuentes `.mmd` editables.
- Exportaciones `.png` opcionales para la memoria o la presentación.

Las imágenes **no se incrustan** en los documentos: la base del curso pide Mermaid, no imágenes. Si una exportación y el bloque Mermaid no coinciden, manda el bloque Mermaid del documento.

| Fuente | Dónde se usa |
|---|---|
| [`organigrama-storygraph.mmd`](organigrama-storygraph.mmd) | `01-analisis.md`, apartado 1.2 |
| [`guion-trabajo.mmd`](guion-trabajo.mmd) | `01-analisis.md`, apartado 7 |
| [`cuadrante-soluciones.mmd`](cuadrante-soluciones.mmd) | `01b-sota.md`, apartado 2 |
